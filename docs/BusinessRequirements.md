# Business Requirement Document

## Problem

Support managers currently rely on Excel reports that are created manually at the end of each month.

This causes:

- Poor visibility
- Slow decision making
- SLA breaches
- High backlog

## Objective

Build a BI platform that provides near real-time insights into support operations.

## Stakeholders

CEO

Support Director

Operations Manager

Team Leads

Support Agents

## Success Metrics

Increase SLA

Reduce backlog

Improve CSAT

Reduce resolution time
